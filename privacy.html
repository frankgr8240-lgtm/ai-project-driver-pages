更新日期：2026-10-06

用途与访问的数据

本工具用于个人项目文件管理和备份。在用户授权及指令范围内， 通过 Google Drive API 访问文件与文件夹名称、标识、大小、 修改时间和文件内容，并执行目录查询、下载、上传及更新。

授权与凭据

Google 账号登录由 Google 处理。本工具使用 OAuth 授权， 不要求用户向本网站提供 Google 密码。 授权令牌和客户端凭据保存在运行工具的设备配置中， 不应提交到本公开网站或 GitHub 仓库。

存储与共享

工具按用户配置将文件保存到指定设备或授权的备份位置。 保存期限由用户的项目和备份策略决定。 不会出售 Google 用户数据，不用于广告投放， 也不会将其用于训练通用人工智能或机器学习模型。 如用户另外指示向其他服务传输数据，应单独确认用途与授权。

撤销与删除

用户可以在 Google 账号的第三方连接管理中撤销应用授权。 撤销授权不会自动删除已经下载或备份的文件； 用户需要在对应存储位置删除文件及不再使用的凭据。

网站托管与联系

本说明网站由 GitHub Pages 托管，访问网站时的数据处理 另受 GitHub 隐私声明约束。

联系： GitHub Issues。 请勿公开提交令牌、密码、私人文件或其他敏感信息。
